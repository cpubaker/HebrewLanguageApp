# Reading Content Instructions

## Scope
- Numbered reading lessons for the Flutter learning app.
- Keep changes narrow and aligned with neighboring lessons in the same level folder.

## File Shape
- Use stable numbered filenames such as `01_yosi_goes_to_school.md`; do not rename unless requested.
- Use UTF-8, simple Markdown only, clean spacing, and nonempty files.
- Start with a Markdown heading; the first heading is the displayed title.
- Put the reading text directly after the title.
- Add supporting sections only when they match the local level pattern.
- Do not treat helper files like this `AGENTS.md` as lessons.

## Level And Hebrew Rules
- `beginner/`: short, concrete, high-frequency sentences; Hebrew body text, vocabulary items, and verb entries must use nikkud.
- `pre-intermediate/`: longer sentences and more topic vocabulary are fine, but avoid advanced syntax.
- `intermediate/` and above: broader vocabulary and denser description are allowed, but keep one focused natural text.
- Preserve natural, correct Hebrew and stay consistent inside each file with spelling, terminology, and translation style.
- For `pre-intermediate/` and higher levels, nikkud is optional unless requested.

## Supporting Sections
- Follow adjacent files before inventing a new lesson shape.
- If a level uses headings like `## Основні слова` or `## Нові дієслова`, keep those headings and focus the list on the text.
- Do not overload one lesson with unrelated glossary or verb items.

## Content Rules
- Keep one lesson centered on one clear situation, topic, or scene.
- Prefer level-appropriate vocabulary and grammar over forced advanced wording.
