# Останні коробки в старій квартирі

ביום שישי בבוקר התחלנו לארוז את הדירה הישנה שגרנו בה כמעט שש שנים.
הבאנו עשרות קרטונים ריקים מהסופר, גליל ניילון בועות, וכמה מדבקות צבעוניות לסימון.
התחלתי מהמטבח, עטפתי כל צלחת וכל כוס בנפרד, וכתבתי על כל קרטון מה יש בתוכו.
בן זוגי פירק את המיטה בחדר השינה, ואני מילאתי שקיות גדולות בבגדים ובמצעים.
בכל פינה מצאנו דברים ששכחנו מזמן: מכתבים ישנים, תמונות, וצעצוע קטן של הכלב.
לקראת הצהריים הגיע המוביל עם משאית, ושני עובדים חזקים התחילו להוריד את הרהיטים הכבדים.
הם הורידו את הספה, את המקרר ואת הארון הגדול במדרגות צרות, בזהירות רבה.
הסתכלתי על הסלון הריק, והרגשתי משהו מוזר: המקום שהיה מלא חיים נראה פתאום קטן ושקט.
לפני שיצאנו, עברתי חדר חדר, בדקתי שלא נשאר כלום, וסגרתי את החלונות.
מסרתי את המפתח לשכן שיעביר אותו לבעל הבית, ונעלתי את הדלת בפעם האחרונה.
בדרך לדירה החדשה ישבנו במונית עמוסה בקרטונים על הברכיים, ולא דיברנו הרבה.
ידעתי שייקח זמן עד שהמקום החדש ירגיש כמו בית, אבל הייתי מוכנה להתחיל מחדש.
