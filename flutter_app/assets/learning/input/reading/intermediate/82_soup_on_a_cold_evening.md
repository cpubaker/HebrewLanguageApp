# Суп на холодний вечір

ביום שישי קר במיוחד החלטתי להכין סיר גדול של מרק עוף, כמו שאמא שלי תמיד הכינה בחורף.
הוצאתי מהמקרר חזה עוף, כרבע עוף עם עצמות, וכמה ירקות שחיכו כבר כמה ימים.
קילפתי גזר, חתכתי בצל וסלרי, ושטפתי תפוחי אדמה וקישוא בזהירות.
מילאתי סיר גדול במים, הוספתי את העוף, והבאתי את הכול לרתיחה איטית.
הסרתי בכף את הקצף שעלה למעלה, ואז הוספתי מלח, פלפל שחור וכף אחת של אבקת מרק.
הנמכתי את האש, כיסיתי את הסיר, ונתתי למרק להתבשל כמעט שעה וחצי.
הריח שהתפשט במטבח הזכיר לי מיד את הבית של ההורים בילדות.
בזמן שהמרק התבשל, חתכתי פטרוזיליה טרייה והכנתי לחם חם לצד.
טעמתי כף אחת, הוספתי עוד קצת מלח, וחיכיתי שהירקות יתרככו לגמרי.
כשהמרק היה מוכן, מזגתי אותו לקערות עמוקות, והאדים עלו אל הפנים שלי.
ישבתי ליד השולחן עם קערה חמה ביד, והרגשתי איך החום מתפשט בכל הגוף.
הבנתי שלפעמים מנה פשוטה כמו מרק עוף שווה הרבה יותר ממה שכתוב במתכון.
