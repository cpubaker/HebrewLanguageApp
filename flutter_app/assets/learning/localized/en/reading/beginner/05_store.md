# The Shop

דָּנָה הוֹלֶכֶת לַחֲנוּת.
הִיא קוֹנָה פֵּרוֹת.
הִיא לוֹקַחַת תַּפּוּחַ אָדֹם.
הִיא לוֹקַחַת בָּנָנָה צְהֻבָּה.
הִיא לוֹקַחַת תַפּוּז כָּתֹם.
הַקּוֹפָאִי נוֹתֵן לָהּ שַׂקִּית.
דָּנָה מְשַׁלֶּמֶת וְחוֹזֶרֶת הַבַּיְתָה.

## Key words

- חֲנוּת - shop; store
- הוֹלֶכֶת - goes; walks (feminine)
- קוֹנָה - buys (feminine)
- פֵּרוֹת - fruit
- לוֹקַחַת - takes (feminine)
- תַּפּוּחַ - apple
- אָדֹם - red
- בָּנָנָה - banana
- צָהֹב / צְהֻבָּה - yellow / yellow (feminine)
- תַפּוּז - orange
- כָּתֹם - orange (colour)
- קוֹפָאִי - cashier
- שַׂקִּית - bag
- מְשַׁלֶּמֶת - pays (feminine)
- חוֹזֶרֶת הַבַּיְתָה - returns home
