# Vocabulary expansion (frequency-driven)

Planning artifacts for growing `hebrew_words.json` toward a top-2000-frequency coverage target.

## Scope

The Flutter client splits learning content across modules:

- `hebrew_words.json` — single-form vocabulary deck (nouns, adjectives, particles, etc.).
- `flutter_app/assets/learning/input/verbs/*.md` — full conjugation lessons (one file per verb, 5 paradigms each).

Verb candidates are tracked separately and **never added to** `hebrew_words.json`.

## Files

- `top_frequency_candidates.json` — curated candidate list across 22 categories, generated by `tools/build_candidates.py`.
- `existing_inventory.json` — snapshot of every entry currently in `hebrew_words.json`, with nikud-stripped Hebrew for diff.
- `existing_hebrew_plain.txt` — flat lookup of nikud-stripped Hebrew strings from `hebrew_words.json`.
- `existing_verbs_plain.txt` — flat lookup of nikud-stripped infinitives from the verb module.
- `words_to_add.md` — diff output for `hebrew_words.json`: missing candidates grouped by category (excludes `verbs`).
- `words_to_add.json` — machine-readable form.
- `diff_summary.txt` — counts per category.
- `verbs_to_add.md` — diff output for the verb module: candidate verbs not yet in `flutter_app/.../verbs/`.
- `verbs_to_add.json` — machine-readable form.
- `pending_audio.md` — tracker for entries added without `audio_file`, queued for batched audio generation.

## Workflow

1. **Plan**: review `words_to_add.md`, decide on the next batch of ~50.
2. **Insert**: append entries to `hebrew_words.json` (no `audio_file` field yet), assign stable `word_id` values.
3. **Track**: log the new `word_id` values in `pending_audio.md` under **Queue**.
4. **Validate**: run `scripts/validate.ps1 content` from repo root.
5. **Repeat** until the missing count reaches zero or the 2000-total target is hit.
6. **Audio (separately)**: run `scripts/generate_word_audio_elevenlabs.py` for the queued ids, then move rows from **Queue** to **Done** in `pending_audio.md` and add the `audio_file` field to the JSON entries.

## Regenerating the diff

After any change to `hebrew_words.json`, rerun:

```
python tools/vocab_diff.py
```

After any change to the verb module, rerun:

```
python tools/verb_diff.py
```

Both scripts overwrite their respective output files based on the current state.

## Notes

`verb_diff.py` uses a heuristic that normalizes ktiv-male (`לִשְׁמוֹעַ`) and ktiv-haser (`לִשְׁמֹעַ`) variants of the same verb. The heuristic strips internal `ו` (vav) letters; rare false matches are possible for short or unusual words.
